# Admin Workflows

This document specifies the admin panel modules for managing explanations, monitoring content quality, and analyzing user metrics.

---

## 1. Explanation Management Panel

*   **List View**: Grid of all questions in the database with status tags: `Needs Explanation`, `Draft`, `Published`.
*   **Search and Filter**: Search by question ID, test title, topic tags, and difficulty.
*   **Bulk Edit Tools**: Select multiple questions and apply a generic explanation pattern or tag rules.

---

## 2. Quality Control Dashboard

*   **Missing Explanations**: Prioritizes questions that have been answered incorrectly most frequently by students but do not yet have an explanation written.
*   **Feedback & Reports**: Displays a list of issues reported by users (e.g., "Explanation is confusing", "Wrong grammar rule linked").
*   **Workflow Actions**: Admins can approve, reject, or assign explanations to different teachers/content writers.

---

## 3. Teacher/Instructor Analytics

*   **Common Mistakes**: Identify questions or grammatical categories that students fail most often.
*   **Engagement Tracking**: See how long students spend reading explanations and whether taking notes correlates with score improvements.
